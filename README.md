# 项目事实

每个项目当前状态的全景档案。

## 这是什么

一个轻量级项目事实仓库，记录各项目（产品、版本、团队、业务、数据资产）当前的**状态快照**，而非历史日志。

## 为什么建

- 团队信息分散在文档、聊天、会议中，难以快速对齐
- 新成员 onboarding 缺乏全景视角
- 定期记录状态快照，减少信息损耗

## 怎么用

直接打开 `index.html` 浏览项目列表，点击卡片进入对应项目的事实页面。

### 目录结构

```
project-facts/
├── index.html        # 首页 — 项目列表
├── README.md         # 本文件
└── *.html            # 各项目事实页面
```

### 添加新项目

1. 新建 `项目名.html`，沿用统一杂志风样式
2. 在 `index.html` 的 `project-list` 中添加对应卡片
